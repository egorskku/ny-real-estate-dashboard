# # 🏙️ NY Housing Market Analysis Dashboard

## Overview

The NY Housing Market Analysis Dashboard is an interactive Streamlit application designed to explore real estate prices across New York City.

The project analyzes how key factors such as location, property size, number of bedrooms, number of bathrooms, and property type influence housing prices. The dashboard provides users with interactive visualizations and filtering tools to better understand the New York real estate market.

This project was developed using Python, Streamlit, Plotly, and a real-world housing dataset.

---

## Features

### Interactive Filters

Users can customize the analysis using:

* Budget range selection
* Neighborhood selection
* Property type selection
* Bedroom filters
* Bathroom filters

### Geographic Price Analysis

An interactive map visualizes property locations throughout New York City.

Users can identify areas with higher and lower property prices and explore the spatial distribution of housing values.

### Property Value Correlation Analysis

A scatter plot examines the relationship between property size (square footage) and market price.

This visualization helps demonstrate how property size contributes to overall housing value.

### Neighborhood Comparison

A ranking chart compares average property prices across different neighborhoods.

Users can quickly identify the most expensive areas in the city.

### Property Type Comparison

A comparative chart analyzes average prices across different property types.

This allows users to explore how housing categories affect market value.

### Data Exploration

A filtered data table allows users to inspect the underlying dataset and export filtered results for further analysis.

---

## Dataset

The project uses the NY House Dataset containing information about:

* Property prices
* Property size (square footage)
* Bedrooms
* Bathrooms
* Property type
* Address information
* Geographic coordinates
* Neighborhood and locality data

To improve visualization quality, automatic data-cleaning techniques are applied within the application to remove invalid records and extreme outliers.

---

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly Express

## Project Goal

The goal of this project is to demonstrate how location and property characteristics contribute to housing prices in New York City through interactive data visualization and analysis.
